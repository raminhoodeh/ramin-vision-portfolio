# Metrics And Goal Setting Playbook

Use this file to shape "what metrics would you track", "what is the north star", or "how would you measure success" answers. This complements the metrics hierarchy in the pricing-metrics-estimation framework with how to choose the right metric for a given product or feature. Do not use it as evidence about Ramin.

## Answer Shape

1. Restate the product's core value and who gets it.
2. Choose one north star that captures delivered value, not vanity reach.
3. Map the input metrics (behaviours the team can move) that drive the north star.
4. Add output metrics (business or user results) that confirm value.
5. Add guardrail or counter-metrics so the goal cannot be gamed.
6. Name the leading indicator you would watch before the lagging one moves.
7. Set a target and a review cadence, and say how you would diagnose a miss.

## Choosing A Good North Star

A good north star reflects real value, moves with product quality, is hard to game, and is understandable across the team. Test it: if this number went up but users were worse off, it is the wrong metric. Always pair it with a counter-metric.

## What Strong Metrics Answers Sound Like

Strong answers separate leading from lagging metrics, always include a guardrail, and connect each metric back to the value the product delivers. Weak answers pick reach or activity vanity metrics, with no counter-metric and no link to value.

## AI Product Metric Additions

For AI products, also track answer quality, helpfulness, escalation and human-handoff rate, hallucination or error rate, confidence calibration, latency, and cost per successful task.
