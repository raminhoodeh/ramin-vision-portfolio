# Ordnance Survey - Geospatial API

## Summary

Ramin worked at Ordnance Survey as Product Manager for a Geospatial API from Dec 2020 to Sept 2021.

This role is important evidence for geospatial data, sustainability applications, government/public-sector product work, Microsoft Power Platform, and formal stakeholder engagement.

## Product Work

Local sources say Ramin led twelve discovery workshops with the Propositions and Innovation team and client stakeholders to discover sustainability applications of geospatial data.

The work helped validate three product concepts for further investment and contributed to defining and launching the first geospatial API on Microsoft's Power Platform.

Local source claims include:

- improved energy clients' ability to forecast carbon impacts on asset valuations by 25 percent within 6 months
- increased geospatial data utilisation by 30 percent across two key accounts by Q3 2021

These metrics should be reviewed before public chatbot use.

## Features Built

The PM Experience source lists features including:

- postcode search
- free text address search
- viewing results on a map
- UX enhancements for map view and scrolling behaviour
- saving text-search results
- saving map hotspots into text search

## Tradeoff Example

Ramin said no to a feature that would let users request that a missing address be added.

Reason:

- developers said data-sending functionality would take significant time
- product stability was a priority after a Microsoft partnership
- validation would require a chain of communication with the AddressBase Premium team
- the timeframe was not feasible
