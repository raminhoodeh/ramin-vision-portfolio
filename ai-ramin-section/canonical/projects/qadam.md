# Qadam

## Summary

Qadam is a catalyst-driven macro intelligence platform for detecting physical-world signals before they become consensus market narratives.

It is a project and portfolio example, not financial advice.

## Problem

Markets often react after physical-world events enter mainstream narratives. Qadam targets the window between physical reality and market awareness by monitoring alternative data signals.

## Architecture

The source architecture describes:

- a local triage/noise gate
- a cloud strategist layer
- weekly quantum-assisted pattern recognition
- deterministic Python orchestration
- five data pipelines: geopolitical/conflict, logistics/infrastructure/OSINT, economic/macro, market microstructure/order flow, and social/sentiment/narrative
- Knowledge Graph
- append-only event log
- risk agent
- postmortem agent
- paper trading proof phase
- human signal approval

## Product Judgement

The architecture separates workloads by timescale. Local inference handles high-throughput triage. Cloud models handle deeper reasoning. Quantum is treated as a weekly batch signal, not a real-time execution dependency.

## Tradeoffs

- Human gate on strategy, not individual trade micromanagement.
- Paper proof phase limits capital deployment but protects against unproven live risk.
- Full production governance, model cards, output classifiers, and audit layers are not yet complete.
