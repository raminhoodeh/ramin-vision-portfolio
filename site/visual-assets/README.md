# Original homepage typography

Self-hosted Latin WOFF2 files for the exact Inter and Instrument Serif families used by src/index.css. Retrieved from the original Google Fonts CSS on22October2026. Source URLs:

- inter-latin.woff2: https://fonts.gstatic.com/s/inter/v20/UcC73FwrK3iLTeHuS_nVMrMxCp50SjIa1ZL7W0Q5nw.woff2
- instrument-serif-italic-latin.woff2: https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7Motmp5g.woff2
- Inter-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/inter/OFL.txt
- Instrument-Serif-OFL.txt: https://raw.githubusercontent.com/google/fonts/main/ofl/instrumentserif/OFL.txt

Both font licenses are included in this folder and embedded as comments in the maintenance page stylesheet. The fonts are unmodified.
